# Distance measures available for a data type

Distance measures available for a data type

## Usage

``` r
distance_choices(type)
```

## Arguments

- type:

  A data type from
  [`data_types()`](https://ebenogoe.github.io/clusnalyst/reference/data_types.md).

## Value

A named character vector (labels as names). The first entry is the
default.
