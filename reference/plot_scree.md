# Scree plot of an ordination

Scree plot of an ordination

## Usage

``` r
plot_scree(ord, n = 10, dark = FALSE)
```

## Arguments

- ord:

  A `cl_ord` from
  [`ordinate()`](https://ebenogoe.github.io/clusnalyst/reference/ordinate.md).

- n:

  Number of axes to show.

- dark:

  Colours for a dark background.

## Value

A ggplot object.
