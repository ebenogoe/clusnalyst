# Plot two distance matrices against each other

Plot two distance matrices against each other

## Usage

``` r
plot_mantel(mantel, labels = c("Distance 1", "Distance 2"), dark = FALSE)
```

## Arguments

- mantel:

  Result of
  [`mantel_test()`](https://ebenogoe.github.io/clusnalyst/reference/mantel_test.md).

- labels:

  Axis labels.

- dark:

  Colours for a dark background.

## Value

A ggplot object.
