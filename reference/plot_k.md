# Plot the cluster-number diagnostics

Plot the cluster-number diagnostics

## Usage

``` r
plot_k(kres, dark = FALSE)
```

## Arguments

- kres:

  Result of
  [`optimal_k()`](https://ebenogoe.github.io/clusnalyst/reference/optimal_k.md).

- dark:

  Colours for a dark background.

## Value

A ggplot object.
