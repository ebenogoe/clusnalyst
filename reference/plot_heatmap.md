# Heatmap of a distance matrix

Heatmap of a distance matrix

## Usage

``` r
plot_heatmap(dist, order = NULL, dark = FALSE, interactive = TRUE)
```

## Arguments

- dist:

  A `dist` object.

- order:

  Optional sample order (for example the tree's tip order).

- dark:

  Colours for a dark background.

- interactive:

  Add hover text to each cell.

## Value

A ggplot object.
